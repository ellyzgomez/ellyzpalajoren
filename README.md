# Ellyz Gomez — Portfolio Website 🌿

A modern, responsive portfolio website for **Ellyz Gomez** (4th-year IT Student, Web Developer & UI/UX Specialist).

## 🚀 Features
- **Editorial / Minimalist Sage Aesthetics**: Ultra-clean layout with custom typography.
- **Dark Mode & Light Mode**: Seamless theme switching with local storage memory and system preference detection.
- **Interactive 3D Certificate Stack**: Interactive certificates powered by React Bits 3D Depth physics with auto-advance on hover and high-res lightbox viewer.
- **Engineering & Capabilities Matrix**: Clean categorization for Development, Design & Tools, and Core Competencies.
- **Interactive Contact System**: Direct email draft generator and FormSubmit AJAX inbox delivery.
- **Resume Download**: One-click download for .docx / .pdf resume file.
- **Fully Responsive**: Optimized for desktops, tablets, and smartphones.

## 🛠️ Built With
- **HTML5** & **CSS3** (Custom Properties, Flexbox, CSS Grid)
- **Vanilla JavaScript** (ES6+)
- **GSAP** (GreenSock Animation Platform)
- **Lucide Icons**
